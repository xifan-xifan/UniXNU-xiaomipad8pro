# Independent collection owner startup configuration (2026-11-20)

The Piano defconfig enables the owner cache check, authenticated startup, boot manifest, Data mount, and SystemOS union mount together. The pinned builder requires authenticated startup and disables the cryptex fallback experiment for union composition. The retained independent source includes conditional compatibility definitions in `osfmk/kern/link_compat.c` that return success for any root device and derive a digest from UUID text. Neither definition appears in the compiled `link_compat.o`, and `nm` found neither definition nor the owner cache routine in the positioned kernel. Enabling the source configuration on this tree would require replacing those compatibility definitions with the authenticated storage path as part of the same change. The checked-in NativeUfs provider exposes `native_ufs_block_authenticates`, but the independent source still lacks the verified volume lookup consumed by the pinned SystemOS and App cryptex patches.
