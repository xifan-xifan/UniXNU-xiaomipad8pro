# Independent kernel SystemOS startup audit (2026-11-20)

The retained independent source at `/tmp/piano-k27-independent.zbovHflG/src/bsd/kern/kern_exec.c` takes a different startup path from the locked UniXNU `d830d23` reference patch `patches/xnu/offline-owner-systemos-mount.patch`. The reference calls `native_owner_cache_prepare` before launchd and requests a read-only SystemOS union mount. The independent source's function of the same name checks the existing read-only APFS root and optionally publishes the boot manifest. It makes no SystemOS mount request in that function. The device repository's NativeUfs code publishes the SystemOS block window for the owner code to find. Publication alone does not establish that launchd sees the SystemOS files. This source comparison identifies a missing comparison point for the independent collection beyond the missing mount and fsck files. Check the complete boot path for an equivalent mount and verify it against the composed root before using that collection for a desktop test.
