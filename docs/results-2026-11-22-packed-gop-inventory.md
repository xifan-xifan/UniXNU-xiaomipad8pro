# Packed GOP inventory and DarwinBoot refusal paths (2026-11-22)

A host readback decompressed the LZMA-guided FVMAIN section from `boot-piano-macos-ram-auto8-darwinboot.img`, `boot-piano-darwinboot-witness.img`, and `boot-piano-darwinboot-mailbox.img` in `out/`. All three contain a DXE driver FFS for SimpleFbDxe (`dcfd1e6d-788d-4ffc-8e1b-ca2f75651a92`), at decoded offsets 3132584, 3139768, and 3139768 respectively. None contains a DXE driver FFS for ScaledFbDxe (`4b2d8e61-3a7c-4f15-9d0e-6c8a1b5f2e47`). The mailbox build log lists both modules, so the packed section is the relevant inventory. The witness run also printed a linear framebuffer configuration before the final memory-map request.

The retained mailbox DarwinBoot source can return `EFI_UNSUPPORTED` for a rejected Mach-O header, an unsupported request or exception level, or a ramdisk descriptor in the ADT with no supplied ramdisk. `ReadBootVideo` checks the GOP on the console handle first and can propagate the GOP validation result. The packed driver inventory therefore rules out ScaledFbDxe as the provider in these images but does not identify the live GOP handle or the historical auto8 refusal site. The separate reset90 probe did log that the loader protocol was unavailable. The APRIORI witness already exercised a later path through loader dispatch, so restoring CapsuleRuntime is unnecessary for reproducing that path. A fresh diagnostic needs stage-specific results on the exact KC and ADT being tested. This audit ran on the host only.

A second readback hashed the Android v2 ramdisk section from all three images. The SHA-256 was `347396a974d94923944e53fcc5dee4f9bfcf940e54c66b750b7c2ac5da5bbdf4` in every case. The witness therefore reached EBS preparation with the same menu, KC, ADT and ramdisk bytes as the earlier auto8 candidate. Its runtime also proves that those bytes pass the witness loader's input checks. The earlier FD uses a different loader build and may handle the inputs differently.

None of the three decoded volumes contains a DXE driver FFS for CapsuleRuntimeDxe (`42857f0a-13f2-4b21-8a23-53d3f714b840`). The witness's confirmed dispatch establishes that this module is unnecessary on the existing witness path. The initial APRIORI decoding attempt was rejected by a header assertion and is not evidence about the order of packed drivers.
