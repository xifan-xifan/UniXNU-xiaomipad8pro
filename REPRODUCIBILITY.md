### Mac host tools (2026-11-19)

NASM 3.02 was built from its source archive in `/tmp/piano-host-tools-20261119`; the executable is `/tmp/piano-host-tools-20261119/prefix/bin/nasm`. ACPICA source archive `acpica-unix-20260930.tar.gz` has SHA-256 `aa18901b92e30749be0edc3081c8d550c61fce4fa37546fc6a65d367a4ae71a5`, matching the official release asset digest. An initial unmodified macOS build compiled all iASL objects but Apple `ld` failed with `pointer not aligned in '_AcpiExDumpNode'+0x3E`; it also warned that `__DATA,__common` alignment was reduced from `0x8000` to `0x4000`. Source inspection showed that ACPICA's `acinterp.h` packs the pointer-bearing debug table unless `ACPI_PACKED_POINTERS_NOT_SUPPORTED` is defined. A second build from the same verified archive, isolated under `/tmp/piano-host-tools-20261119/iasl-packed-test`, set `OPT_CFLAGS="-DACPI_PACKED_POINTERS_NOT_SUPPORTED -O2 -D_FORTIFY_SOURCE=2"`; it linked successfully and reports iASL 20260930. The resulting executable SHA-256 is `257a9054016aa49a6ac88bd0b717f555ba90351375185d0e739cbabd12ee7d6b`. Functional validation compiled ACPICA's `tests/misc/converterSample.asl` with 0 errors and 0 warnings; the generated AML SHA-256 is `8f75f6e441432b4349b4cb400dd0d6bd2e6acbff08d70c7e8c2b220d32964a47`. Both tool builds and test outputs remain outside the repository. This is a local host-tool result, not a native image build or device test.

The host-side ABL checks previously logged `slot-retry-count:a` without validating its format or ensuring it stayed unchanged before reboot. `maint-session.py` now parses the 3-bit A/B retry field (0-7) at `abl-check`, then at `abl-final` requires slot A to be current, successful and bootable and the retry count to match the recorded value. This uses the AOSP `bootloader_control` layout, where `tries_remaining` is 3 bits and `successful_boot` is separate. A fake-Fastboot host test covers accepted state, out-of-range/missing values, changed retry count, and unsuccessful/unbootable/wrong-current slot states. The test passed on the Mac with Python 3.9.6; no Fastboot command or tablet operation was run.
